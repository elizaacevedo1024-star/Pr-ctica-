## 📌 Descripción del Proyecto

Este repositorio reúne una serie de ejercicios prácticos desarrollados para consolidar los conceptos fundamentales de la **Programación Orientada a Objetos (POO)** en **PHP**. A través de estos scripts se abordan pilares clave como la herencia, el encapsulamiento, la restricción de clases, el uso de constantes y los métodos estáticos.

---

## 📁 Archivos y Contenido

- **`Area_Perimetro.php`**: Implementación de la clase `Circulo` para calcular área y perímetro mediante el uso de constantes de clase y la constante nativa `M_PI`.
- **`Coche.php`**: Ejemplo de encapsulamiento con propiedades protegidas, getters, setters y sobrescritura de métodos en clases hijas.
- **`Enlace_Estático.php`**: Demostración del comportamiento del enlace estático tardío (*Late Static Binding*) mediante la instrucción `static::`.
- **`Estatico.php`**: Uso de la palabra clave `self::` y `parent::` para el acceso a propiedades y métodos estáticos dentro de una jerarquía de clases.
- **`Estudiante_Docente.php`**: Modelado de una jerarquía de herencia donde las clases `Docente` y `Studente` extienden de la clase base `Persona`.
- **`Problema_3.php`**: Ejemplo del uso de la palabra clave `final` para prevenir que una clase sea heredada por otras.
